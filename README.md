💸 Expense Tracker System

A simple and intuitive web-based Expense Tracker built with Node.js and MySQL.
Keep track of your expenses, stay organized, and manage your budget efficiently!








🚀 Features

🔐 User Authentication

Secure Login and Sign Up.

Each user manages their own expenses.
